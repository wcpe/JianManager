# 功能规格：实例日志安全高级查询表达式与预算控制（FR-558）

- 状态：✅ 已交付@v0.24.0（开发版，联合验收通过）
- 关联 PRD：FR-558
- 依赖：FR-557 的 Query View、字段筛选、预算和错误状态模型
- 决策：[ADR-109：高级过滤安全边界](../../adr/109-instance-logs-advanced-query-boundary.md)

## 1. 目标

为熟悉 LogsQL 的运维人员提供高级查询入口，同时保留视觉筛选器。高级表达式只能在平台已有授权范围内工作，不能成为绕过目标、时间、权限或预算限制的旁路。

## 2. 查询语义

- 普通模式由级别、来源、实例、节点、字段、流、关键词和时间范围生成结构化查询。
- 高级模式允许提交 LogsQL 表达式；Control Plane 不把用户表达式当作完整安全 selector，而是独立叠加授权 selector、时间范围和预算。
- 高级表达式与普通查询使用相同 Query View、覆盖判断、质量标记、分页、取消和导出闸门。
- 节点日志和平台日志不进入高级 LogsQL 模式，只使用普通文本窗口能力。

## 3. 安全与资源控制

1. 任何用户表达式都不能扩大已授权实例集合或节点集合。
2. 服务器端强制时间范围、最大返回行数、最大字节数、查询超时、最大扇出和查询文本长度。
3. 用户取消、HTTP 断开、Worker 超时和 VL 错误必须向下游传播并释放查询资源。
4. 高级查询输入、执行人、目标 scope、耗时、结果预算和失败原因写入必要审计信息，不记录敏感凭据。
5. 不支持的 LogsQL 管道、字段或聚合返回明确错误，不降级为空结果。

## 4. 验收标准

- 未授权实例写入表达式、修改 source selector、扩大时间范围均无法突破服务端授权测试。
- 超长表达式、超时、超行数、超字节数、429、取消和 Worker 不支持各有后端测试与前端状态。
- 普通模式与高级模式在相同 scope/filter/time 下的覆盖、分页、导出和质量语义一致。
- 真机验证高级查询可以取消，取消后再次查询可用；不会阻塞筛选区和日志窗口。
- 高级查询只能用于实例 VL 数据面；节点/平台文本日志页面不显示该入口。

## 5. 非目标

不提供 VL 删除、改 retention、租户管理、任意 HTTP 代理或保存查询会话功能。

## 6. 实施与验收记录（2026-11-12，v0.24.0 开发版）

- 默认实例工作台及普通授权用户均可使用高级过滤；节点/平台文本模式不显示高级入口。普通关键词去抖；高级草稿由 Enter/查询显式应用，未应用草稿、失败、占位或在途响应不能导出。
- `keyword` 与 `logsQL` 共用 8 KiB UTF-8、字符串/括号/半开区间词法边界。支持单双引号、反引号和引号内正则 `|`；未引用管道、注释和控制字符拒绝。此能力为 filter-only，不开放任意 stats/union 管道。
- 授权 selector、HTTP `[from,to)` 与用户过滤独立下发；普通入口不能绕过管道检查。授权集合、主体、权限 scope、已应用过滤和时间范围绑定 View，查询、分页、分析和导出不混用旧草稿或其它 scope。
- 高级历史查询预算最多 1000 行 / 32 MiB / 30 秒 / 64 Worker，客户端只能收紧；整窗导出仍受既有配置与资源闸门限制。`query_meta` 来自真实 CP；旧 CP 缺执行确认时明确拒绝伪高级结果。审计保留主体、范围、内容摘要、耗时和结果，不记录原始敏感表达式。
- **真实开发环境**：同一高级条件得到 5 行 Search、字段值、stream 与时间桶，并导出 5 行 NDJSON；主页面真实提交 `bad | stats count()` 收到 HTTP 400，显示拒绝原因且不是成功空结果。中文亮色与英文暗色验证已应用条件、字段包含变草稿后导出禁用、再次应用后结果一致，界面保持响应。
- **真实浏览器取消通过**：对真实开发 CP 的在途高级请求点击取消，Chromium 网络事件确认为 `net::ERR_ABORTED`，页面显示取消并保持控件可用；随后重新查询独立标识得到 5 行，浏览器错误为 0。仅通过 CDP 限制响应带宽以保证可观察的在途窗口，没有 mock API；下游 Worker/VL 取消释放另由 HTTP/gRPC/真实 VL 集成测试验证。
- **自动化与隔离集成**：授权 OR/来源前缀/时间隔离、View 与 Export 绑定、8 KiB 上限、仅收紧预算、HTTP AbortSignal、取消后可再次查询、普通/高级切换缓存身份、旧端不支持、400/422/429/超时与质量门禁均通过。最终前端日志范围 23 文件 / 282 用例与对应 Go 回归通过。

高级过滤与有界字段探索仍由不同预算治理；前者不代表任意 VL 管道或无限扫描能力。开发环境结果不外推为生产长稳/吞吐验收。
