# 功能规格：实例日志浏览器端实时流式跟随（FR-559）

- 状态：规划草案
- 关联 PRD：FR-559
- 依赖：FR-557 的实例日志结果模型、固定视口与原生选择行为
- 需要 ADR：HTTP 流式桥、连接生命周期、慢消费者与重连语义

## 1. 目标

把 Worker 已有的日志 Tail server-stream 通过 Control Plane 安全桥接到浏览器，让实例日志页面在不刷新、不跳布局的情况下显示新事件，同时允许暂停回看和恢复跟随。

## 2. 数据与连接边界

- 浏览器只连接 Control Plane；Control Plane 按当前用户、Query View 和授权范围创建 Worker Tail 请求。
- 节点/平台普通文本日志继续使用有限窗口刷新，不接入本流式 VL 桥。
- 初始历史窗口与实时事件使用同一筛选表达式和实例授权范围。
- 跨多个流只保证现有契约允许的流内顺序；不得对跨流事件宣称严格全局排序。

## 3. 连接状态

- `idle`：未开始实时跟随。
- `connecting`：正在建立查询连接。
- `live`：持续接收事件。
- `paused`：用户主动暂停或正在回看，连接可按策略取消/保留，但不得继续强制滚动。
- `reconnecting`：断线后按退避策略重连。
- `stopped`：用户停止或筛选条件改变，旧连接必须取消。
- `unsupported/error`：旧 Worker、不支持的查询能力或权限/预算错误，明确提示并可回退到轮询。

## 4. 资源治理

1. 每个浏览器连接有行数、字节数、缓冲区和最长运行时间上限。
2. 慢消费者触发丢弃/暂停/断开中的一种明确策略，并向用户显示状态；不得无限积压内存。
3. 浏览器关闭、路由离开、筛选变化、用户停止和 HTTP 断开都必须向 CP、Worker 和 VL 传播取消。
4. 重连必须带当前查询身份；不能把旧 View 的事件追加到新筛选结果。
5. 旧 Worker 或不支持 Tail 的节点回退轮询，回退原因可见。

## 5. 验收标准

- 真 VictoriaLogs + 真 Worker + CP + Chromium 环境中，持续写入实例日志能在浏览器实时出现。
- 点击暂停后新增事件不打断滚动位置和原生文本选区；恢复后只接收当前查询身份的事件。
- 断开网络后显示重连状态，恢复后能继续；切换筛选/实例/页签会取消旧连接且无旧事件串入。
- 触发行数/字节/时间预算和慢消费者上限时，页面显示明确原因，服务端资源最终释放。
- 权限撤销、Worker 不支持、VL 不可用、HTTP 取消分别有自动化覆盖和至少一次真机验证。

## 6. 非目标

不把节点/平台文件日志改造成 VL 流式数据面；不提供跨流严格全局顺序、无限历史回放或任意客户端直连 VL。
