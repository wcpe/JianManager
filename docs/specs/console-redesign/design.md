# 功能规格：高密度控制台重塑

> 状态：✅ 已交付@v0.13.0　·　关联 PRD：FR-267~272　·　日期：2026-07-02

## 1. 背景与目标

当前控制台经历多轮渐进式 UI 增强后，存在三类问题：

- 顶级导航仍按“集群 / 观测 / 运营 / 系统”等功能域组织，单服能力被分散到多个主导航入口，用户管理服务器时需要来回跳转。
- 单服入口默认偏向可组合画布，适合高级拼屏，但不适合作为所有用户的稳定主控台。
- 页面风格已统一为早期靛蓝圆角，但用户确认的当前方向是 A+C：A 的亮色高密度云运维台作为默认主题，吸收 C 的方块拓扑 Logo/Favicon 与 Jian 绿品牌语言；B 保留为后续暗色主题方向。

本批目标：把 JianManager 控制台主轴调整为 **平台 → 节点 → 服务器**，以单台服务器为核心操作对象，先用现有 mock-api 做可走查的前端原型。

## 2. 范围

### 范围内

- FR-267：高密度控制台设计系统底座。
- FR-268：页眉节点作用域 + 左侧导航 IA + 页面归位。
- FR-269：服务器统一控制台 `/instances/:id`。
- FR-270：节点控制台与高密度服务器列表的设计落点。
- FR-271：平台首页高密度总览的设计落点。
- FR-272：其他页面归位与 A+C 皮肤收口。
- 第一版实现只改前端与文档，数据来自既有 REST API 与 MSW mock-api。

### 范围外

- 不新增 Go 后端接口、proto、数据库 schema。
- 不移除 FR-166 可组合卡片画布、FR-167 超级工作台、FR-168 导播台。
- 不一次性重做所有历史业务页面的深层内容；先完成外壳与服务器控制台原型。

## 3. 信息架构

### 3.1 顶部页眉

页眉承担三件事：作用域、位置、全局即时操作。

```text
[全部节点 ▾]   平台 › node-01 › mc-survival   搜索服务器 / 节点 / 操作  Ctrl K   节点 3 · 服务器 25 · 崩溃 1   任务 2 · 46%   通知   账户
```

槽位：

| 槽位 | 说明 |
|---|---|
| 节点作用域 | 全部节点 / 单节点，影响全部服务器列表、命令面板实例搜索与创建实例默认节点 |
| 面包屑 | 平台 / 节点 / 服务器三级路径 |
| 搜索 | Ctrl/⌘+K，全局搜服务器、节点、页面、操作；实例结果受节点作用域收敛，节点结果仍全局可搜以便切换作用域 |
| 集群状态 | 节点数、服务器数、崩溃数 |
| 任务进度 | 展示活跃任务数量与平均进度 |
| 通知 | 统一通知入口 |
| 账户 | 当前用户、角色、退出登录 |

品牌与主题不占用页眉宽度：品牌固定在左侧栏顶部，主题色 / 明暗入口保留在侧栏底部。

## 4. 服务器统一控制台

`/instances/:id` 是单台服务器的稳定详情页，默认展示固定分区控制台。

```text
服务器控制台 /instances/:id

状态条：
  RUNNING · node-01 · :25565 · 在线 42/200 · TPS 19.8 · MSPT 34ms
  [重启] [停止] [强杀] [打开终端]

分区：
  概览 / 控制台 / 文件配置 / 监控 / 玩家 / 插件 / 备份定时 / 业务 / Bot
```

第一版实现：

- 概览：KPI 条、趋势预览、最近事件、关注事项、日志/玩家预览。
- 控制台 / 文件配置 / 监控 / 插件 / 业务 / Bot：优先复用现有工作区卡片内容。
- 玩家 / 备份定时：第一版可用高密度预览或占位，后续按 FR-269 继续补深层操作。

## 5. 视觉规范

- 主题：A+C Jian 绿默认高密度控制台；B 保留为后续暗色主题方向，不作为默认亮色基调。
- 背景：`#F5F6F8`；面板：`#FFFFFF`；边框：`#D7DCE3`。
- 主色：Jian 绿 `#158053`；辅助钴蓝 `#2563EB`；成功绿 `#16A34A`；警告琥珀 `#D97706`；危险红 `#DC2626`。
- 字体：system UI；数字使用 `tabular-nums` / 等宽风格。
- 间距：6-8px 为主，表格与卡片紧凑排列。
- 形状：小圆角或方角，细边框，弱阴影。

## 7. 验收标准

- 页眉展示节点作用域、面包屑、搜索、集群状态、任务、通知与账户入口；品牌在侧栏顶部，主题入口在侧栏底部。
- 节点作用域实际联动全部服务器列表、命令面板实例结果与创建实例默认节点；节点搜索结果不受作用域限制，便于从命令面板切换节点。
- 侧栏按“平台首页 / 服务器 / 群组网络 / 观测 / 平台管理”组织，单服能力不再散落在主导航。
- `/instances/:id` 能直接打开服务器控制台，并显示状态条、操作按钮和固定分区。
- mock 模式下无需 Go 后端即可走查服务器控制台概览与主要分区。
- mock 模式下至少提供 1000+ 服务器数据，平台首页与全部服务器的高频列表必须通过虚拟渲染控制 DOM 数量，并纳入 benchmark。
- 旧超级工作台、导播台、可组合画布能力不被删除，仍可通过对应入口访问。
- 面包屑与页面标题符合新 IA，不再出现“实例详情只跳画布”的断裂感。
- 前端相关测试和构建通过；若本地未安装依赖导致无法运行，交付说明中明确记录。
