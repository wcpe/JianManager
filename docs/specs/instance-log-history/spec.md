# FR-345 · 未运行/历史日志查看（终端回放 DB 历史 + 独立历史增强）

> 状态：✅ 已交付@v0.18.0 · 类型：feat（增强 FR-039 终端 / FR-049 日志中心）
> 盘问结论（Q4=回放+独立增强）：实例停止/崩溃时终端自动从 DB 回放最近历史，关服不清屏；独立历史查看支持时间筛选/搜索/导出（实例级入口）。软依赖 FIX-3（优雅关服使关服日志先落库、回放才完整）。

## 目标

1. 实例**停止（STOPPED）**时，终端区不再是空白「实例未运行」占位，而是从 DB 回放该实例最近历史日志（含关服过程/崩溃现场），只读、可滚动、滚到底看最新。
2. 手动关服后不「变黑」——历史日志留存可见（DB 持久化，重连/切页签/刷新不丢）。
3. 独立历史查看：从终端区链到完整日志页并**预筛选到本实例**，复用既有搜索/时间筛选/导出（FR-049/050）。

## 现状（复用，无后端改动）

- 实例日志已持久化入库（`LogService`，FR-049）；`GET /logs`（`instanceId/source/level/keyword/from/to` 过滤 + 分页）与 `GET /logs/export`（NDJSON）已就绪，前端 `useLogs`/`exportLogs` 已封装。
- 终端 `TerminalPane`：`RUNNING` 可写、`STARTING/STOPPING/CRASHED` 连只读终端看实时输出、**`STOPPED` 展示静态占位（不连 WS，避免 FIX-B 死循环刷断连）**——即用户「关服后变黑看不到日志」的位置。

## 设计（前端）

- 新增 `StoppedLogsView`：`useLogs({ instanceId, source:'instance', pageSize:N })` 拉最近历史（后端 time DESC，正序展示旧→新贴近终端），暗色只读、加载后滚到底；头部提示「实例未运行，显示历史日志」+「查看完整历史」链到 `/logs?instanceId=<id>`；error/warn 级别着色。
- `TerminalPane` 的 `STOPPED` 分支由静态占位改渲染 `StoppedLogsView`（其余状态不变：CRASHED 等仍连只读实时终端）。
- `LogsPage` 从 URL `?instanceId=` 初始化实例筛选，令深链预筛选到本实例（复用既有搜索/时间/导出）。

## 非目标

- 把 DB 历史预灌进 xterm 缓冲（改用独立只读日志视图，更简单、可滚动/着色）。
- 新日志存储/检索能力（复用 FR-049）。
- CRASHED 实时终端改造（其已连只读终端看现场；DB 回放仅用于无实时连接的 STOPPED）。
