# 功能规格：发布页文件资源管理器（专业文件树库重写）

> 状态：待审　·　关联 PRD：FR-261　·　增强 FR-250/254

## 1. 背景与目标

FR-250 发布编排器（本地暂存 + 延迟批量上传）+ FR-254 拖拽编排已落地，但文件树用的是自造 ClientFileTree 组件——功能弱，缺新建文件夹、重命名、多选、键盘快捷键。真机诉求：发布页需要一个完整的文件资源管理器，能像本地文件管理器一样编排目录结构。

**目标**：用 react-arborist 专业文件树库替换 ClientFileTree，支持新建文件夹/重命名/多选/删除/拖拽上传/zip 解压/移动/冲突提示。保留"本地编排 → 点发布才上传"架构。

## 2. 需求

### 范围内
- **react-arborist 替换 ClientFileTree**：专业文件树组件，支持展开/折叠/拖拽排序
- **新建文件夹**：工具栏按钮，在选中目录下新建
- **重命名**：双击文件/文件夹名进入编辑模式
- **多选**：Ctrl+点击追加选、Shift+点击连选
- **删除**：Delete 键删除选中项（带确认提示）
- **拖拽上传文件**：拖文件到指定目录自动归入
- **拖拽上传 zip**：拖 zip 文件进来自动解压到当前目录（复用 BUG-G 的 zip-filename-decode.ts 处理 GBK）
- **拖拽移动**：拖文件/目录到另一个目录下调整结构
- **同名冲突提示**：移动/上传/解压遇到同名 → 弹窗「忽略 / 覆盖 / 保留两者」
- 保留现有"本地编排 → 点发布才批量上传"架构（草稿仅 File + name/size/path）
- 保留 sync 模式（覆盖/仅一次/忽略）配置
- i18n zh/en

### 不做
- 文件内容预览/编辑（YAGNI）
- 文件搜索/过滤（YAGNI，后续按需加）
- 权限管理（单运营者场景）

## 3. 设计

### 3.1 组件结构
- `FileExplorer`（新组件，替换 ClientFileTree）
  - 内部用 react-arborist 渲染树
  - 工具栏：新建文件夹 / 上传 / 删除 / 展开全部 / 折叠全部
  - 右键菜单：重命名 / 删除 / 新建文件夹
  - 拖拽落区：整个树区域都是 drop target
- 保留 `client-publish-wizard.ts` 的草稿管理逻辑（File 暂存、path 编排）

### 3.2 状态管理
- 文件树数据结构：从草稿 files 列表派生（path → 目录树）
- 新建文件夹：在草稿列表加一个空目录占位
- 重命名：改草稿列表中对应文件的 path
- 删除：从草稿列表移除选中文件
- 移动：改草稿列表中对应文件的 path（换父目录）

### 3.3 zip 解压
- 复用 `lib/zip-filename-decode.ts`（BUG-G 修复，支持 GBK/UTF-8）
- 解压后文件作为草稿加入文件树
- 同名冲突走统一冲突处理

### 3.4 冲突处理
- 同名（同路径）文件存在时弹窗
- 三个选项：忽略（不加入）/ 覆盖（替换）/ 保留两者（新文件加后缀）
- 批量冲突时可选"全部忽略"/"全部覆盖"/"全部保留"
