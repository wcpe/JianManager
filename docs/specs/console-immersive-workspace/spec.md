# 控制台沉浸工作台（FR-420 / FR-421）

- 状态：🔨 开发中
- 关联：ADR-087、ADR-086、ADR-067、FR-414、FR-418
- 目标版本：v0.22.0

## 1. 目标

将实例控制台变为专注但可发现的全屏工作台：收起实例详情页的外围界面（侧栏、顶栏、Tab 栏），同时让多实例监看、分屏和复制无需记忆 tmux 键位。

## 2. FR-420：沉浸工作台壳

- `F11` 进入/退出；`Esc` 在无浮层时退出——**裸 ESC 双击语义**（2026-09-07 增补）：非输入焦点下的
  第一次 ESC 仅 toast 提示（1.6s 窗口期内再按一次才退出整个工作台），内层的清选区/关菜单等
  语义照常先跑；输入类元素（命令栏补全 / Ctrl+R 搜索 / 日志搜索框）里的 ESC 完全放行不拦截。
  顶部关闭按钮与 F11 同效。
- 进入后侧栏、全局顶栏和实例 Tab 栏退场；连接和缓冲不断开。
- 顶部固定工作台头部：当前实例名称/运行状态、TPS/在线/CPU（无探针明确显示“需探针”）、退出按钮和布局操作。
- 日志画布置于圆角工作面内，空输出显示等待状态；命令栏保留在每个工作面底部。
- 视觉采用中性石墨黑表面与克制主色强调；沉浸 pane 的命令输入固定深色背景与浅色前景，不能继承亮色主题的白底/白字组合。
- 不存在 `Ctrl+B`、键位帮助、tmux 状态栏或隐藏的前缀状态。

## 3. FR-421：可视化多 pane

- 一个工作台最多 4 个 pane；可见按钮提供“左右分屏”“上下分屏”“添加控制台”。
- 分屏/添加后弹出实例选择器；pane 标题栏可随时“切换实例”。
- 单击 pane 聚焦；聚焦 pane 有明确高亮边框。标题栏提供最大化/还原与关闭；最后一个 pane 不可关闭。
- pane 布局保留在**标签页会话内**（sessionStorage，2026-09-07 修订，替代早先「只保留当前内存
  会话，刷新后回到单 pane」）：F5 刷新后工作台原样恢复（恢复时重编 pane id 防与新会话生成序列
  撞车），关闭标签页后回到单 pane。
- 复制完全复用现有鼠标锚点选择、行复制、堆栈整块复制和 HTTP 剪贴板兜底；不提供键盘复制模式。

### 3.1 会话生命周期：共享、保活与释放边界（2026-09-07 增补）

- 沉浸 pane 与实例页主控制台**共享同一个** `terminalSessionManager` 会话（同 instanceId 同缓冲）。
- **pane 卸载绝不触发 release-dispose**：沉浸嵌套 `TerminalPane` 硬编码 `persistSession`，卸载只退订；
  管理器另对「进入沉浸台前已存在的会话」调 `pin()`（FR-296 热集语义）形成双保险——即使某表面
  误调 `release()`，pin 也会拦下 dispose。
- 反例警示（Bug 复盘）：曾因沉浸 pane 未传 persistSession，退出沉浸台时把主视图的会话连 WS 带行
  缓冲一起释放，表现为「退出沉浸台后控制台空白」。
- 会话整体生命周期的兜底由 FR-296 的热集 LRU 淘汰承担，不为沉浸台单独扩容或常驻豁免。

### 3.2 工作台家族融合：入口与职责分层（2026-09-07 增补，ADR-087 修订）

- **职责分层**：超级工作台（FR-167）= 监看混排墙（终端/监控/资源等多卡自由网格 + 预设）；本工作台
  （对外称**专注终端**）= 纯终端重度操作（树形等分、F11 专注、原生命令栏）。两者共享会话，
  表面切换不断连、不丢缓冲。
- **超级工作台入口**：其工具条「专注终端」按钮以画布上首个终端卡实例为起点进入；画布无终端卡时
  按钮常驻禁用并提示先拖入终端卡。退出回到来路（工作台页或实例页）。
- **命名统一**：`consoleImmersiveEnter`「专注终端」、`consoleImmersiveExit`「退出专注终端」、
  aria `consoleImmersiveLabel`「专注终端工作台」；「沉浸工作台」保留为内部/文档称谓。

## 4. 明确不做

- tmux/window/session/prefix key 概念。
- `Ctrl+B`、`Ctrl+A` 等全局快捷键抢占。
- `.tmux.conf` 式自定义键位。
- pane 布局跨浏览器会话持久化（localStorage / 服务端）不做——sessionStorage 标签页会话级
  保留即为上限（2026-09-07 修订，原「跨刷新持久化」表述随 §3 同步收紧）。
