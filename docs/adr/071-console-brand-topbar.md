# ADR-071: 控制台品牌顶栏贯通（T 型外壳）与节点作用域下拉下线

- **日期**: 2026-07-15
- **状态**: accepted（修订 FR-162 顶栏「侧栏保持全高、内容区之上另起页眉」的原布局；下线 FR-268 引入的页眉节点作用域下拉，`selectedNodeId` 数据面保留）
- **上下文**: 原控制台外壳为「左侧全高侧栏 + 右侧内容列，内容列顶部再起一条页眉」。侧栏顶部的 logo 区（`py-3.5` + `size-8`，≈60px 高）与页眉（`h-14`，56px）各自带 `border-b`，两条水平分割线在侧栏右缘错位约 4px，交界处呈可见「台阶」；侧栏右缘阴影与页眉下缘描边在左上角交叉无收束。此外页眉左侧「节点作用域下拉（FR-268）」与面包屑（FR-134）两种导航型控件挤在同一区争位、视觉权重不一。二次审视发现该下拉仅少数页面消费 `selectedNodeId`（全部服务器列表、侧栏服务器选择器搜索、Ctrl+K 命令面板、新建实例向导预填），在绝大多数页面无任何可见作用，且其主要生效页「全部服务器」本身已自带节点筛选、进页还会清空该作用域，性价比低。
- **决策**:
  1. **T 型外壳**：`jm-console-shell` 由横向 flex 改为纵向；顶部为**横跨整宽的全局顶栏**，其下为一行「侧栏 + 工作区」（新增 `data-slot="console-body"` 包裹）。侧栏由「全高」下移到顶栏之下，logo 不再驻侧栏。侧栏折叠动画（drawer 宽度过渡 + 内容区 clip-path/transform 补偿）与折叠状态机（`data-sidebar-target/layout/motion`）原样保留，仅结构下移一层。
  2. **品牌区宽度与侧栏同步、分割线贯通**：顶栏左端「品牌区」（`.jm-brand-segment`）宽度经 CSS 绑定 `--sidebar-expanded-width`/`--sidebar-collapsed-width`，随 `data-sidebar-target` 与侧栏同步收放、同 `--sidebar-motion-duration` 过渡；其右缘描边与侧栏右缘对齐 → 左列一条连续竖线；顶栏下缘 = 侧栏上缘 → 一条连续横线。原 4px 台阶消除（实测：品牌区宽 240 = 侧栏宽 240、右缘同 x=240、侧栏顶 = 顶栏底 = 56）。
  3. **折叠触发器迁移**：logo 整体作为折叠触发器（FR-181，展开点击=收起、折叠=展开）连同显式收起按钮从侧栏 logo 区迁入顶栏品牌区，行为与无障碍标签不变。窄屏（<sm）侧栏隐藏，品牌区随之 `hidden`，顶栏回落为「面包屑 + 操作区」满宽，移动端体验不变。
  4. **节点作用域下拉下线，数据面保留**：从页眉移除 `NodeScopeSelector`（FR-268）UI。`console` store 的 `selectedNodeId` 字段及其消费方（`InstancesPage` 自带节点筛选、`ServerSelector` 搜索、`CommandPalette` 实例检索、`InstanceWizardPage` 预填）全部保留——它们读到 `null`（=全部节点）即工作，仅失去「跨页预置作用域再全局搜索」这一冷门用法。
- **理由**:
  - 交界处台阶的根因是「侧栏 logo 区」与「内容页眉」两个独立带下边框的块高度不齐；把 logo 抬进唯一的整宽顶栏，天然只剩一条横分割线、一条竖分割线，是对「消除交界」最彻底的解法（优于仅对齐两块高度的方案 A / 悬浮留白的方案 B）。
  - 品牌区宽度复用既有侧栏宽度变量与过渡时长，折叠时与 drawer 同步收放，无需新增动画状态机，改动面收敛在一层结构 + 一段 CSS。
  - 节点作用域下拉在用户实际浏览的页面上「什么都不做」，且与全部服务器页自带筛选重复；下线后页眉左侧只剩面包屑，顺带消除「重下拉 vs 轻面包屑」争位。保留数据面确保消费方零回归。
- **后果**:
  - `DashboardPage` 外壳改纵向布局并新增 `console-body` 行；`ConsoleHeader` 承载品牌区（新增 `BrandSegment`）；`ConsoleSidebar` 移除 logo 区块与 `collapsed` 冗余入参；`index.css` 新增 `.jm-brand-segment` 宽度同步规则（明暗两套右缘描边）。
  - `header.nodeScope` i18n 键与 `NodeScopeSelector` 组件停用（`console.allNodes` 仍被 `NodeSwitcher`/告警等复用，保留）。
  - 相关布局回归测试与真机 e2e（顶栏品牌、折叠触发器定位、FR-037 纵切）随之更新：折叠开关断言从「侧栏内」改为「顶栏内」。
  - PRD 中 FR-268「页眉节点作用域」子能力标注为已下线（数据面保留）；FR-162/FR-181/FR-134 的顶栏描述以本 ADR 为准。
- **替代方案**:
  - **方案 A（仅对齐两块高度、作用域并入面包屑首段）**：改动最小，但侧栏与内容仍是两个块、竖向交界依旧需各自收边；用户要求最彻底的「交界线消失」，故取 C。
  - **方案 B（悬浮双面板 + 间隙留白取代交界线）**：视觉更「潮」，但偏离现有朴素扁平基调、且改动 shell 边距与折叠补偿更大，否决。
  - **节点作用域改为「仅在生效页显示」**：其唯一强生效页已自带筛选，「上下文显示」等于「几乎不显示」，不如直接下线清爽，否决。
