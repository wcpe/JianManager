# ADR-057: A+C Jian 绿默认高密度运维 UI 风格

- **日期**: 2026-07-02
- **状态**: accepted
- **关联**: FR-267、FR-268、FR-269、FR-272、ADR-032

## 上下文

ADR-032 与 FR-163 建立了早期圆角设计系统。后续在 1000+ 实例、服务器统一控制台、导航外壳与移动端响应式走查中，用户确认默认方向为：A 的亮色高密度云运维台作为默认主题，吸收 C 的方块拓扑 Logo/Favicon 语言；B 只保留为后续暗色主题方向。

## 决策

控制台默认视觉采用 **A+C Jian 绿高密度运维风格**，作为全站亮色默认基调。

原则：

- 背景、面板、边框保持云运维台式克制层级：背景 `#F5F6F8`、面板 `#FFFFFF`、边框 `#D7DCE3`。
- 主色使用 Jian 绿 `#158053`，辅助识别可使用钴蓝 `#2563EB`；状态色继续固定语义：成功绿、警告琥珀、危险红。
- 圆角收敛到小圆角，默认半径为 `0.375rem`，避免大圆角卡片堆叠。
- 控制台、表格、状态条与列表采用紧凑间距、细边框、等宽数字和 `tabular-nums`。
- Logo/Favicon 采用 C 方案的方块拓扑语言，与 Jian 绿主色共同构成品牌识别。
- 暗色主题沿 B 的高密度专业运维方向保留，可在不改变 IA 与组件结构的前提下继续深化。

本 ADR 不废弃 ADR-032 的 token 化路线；它将当前默认品牌色、形态与密度从早期靛蓝圆角方向修正为 A+C Jian 绿高密度方向。低频向导页、登录页等仍可保持更舒展的布局，但不能偏离全局 token 与品牌资产。

## 理由

- 服务器管理需要一屏速扫状态、告警、资源与操作，默认亮色应优先支持高密度运维场景。
- Jian 绿能和项目名、Logo/Favicon 方块拓扑语言形成更稳定的品牌记忆点。
- 继续保留 B 暗色方向，可以解决深色模式的专业感与长时间盯屏需求，但不影响默认亮色的一致性。
- 小圆角、细边框和紧凑表格能降低“玩具感”，更接近专业云运维后台。

## 后果

- `index.css` 的根主题变量以 A+C Jian 绿为默认：`--primary: #158053`、`--brand-forest: #158053`、`--brand-cobalt: #2563EB`，结构色使用 `#F5F6F8` / `#FFFFFF` / `#D7DCE3`。
- `ThemeSwitcher` 保留旧 `indigo` 存储值作为默认品牌主题兼容名，但视觉含义已变为 Jian 绿默认。
- 新控制台组件优先使用紧凑布局、细边框、等宽数字与小圆角；避免重新引入大面积渐变、装饰性卡片或大留白。
- 前端测试需关注高密度布局下的可访问名称、导航结构、暗色模式表面层级与大数据虚拟渲染，不以静态截图断言为主。

## 落地状态

截至 2026-07-05，FR-267 / FR-272 已按本 ADR 完成默认视觉收口：

- 默认亮色主题已切到 A+C Jian 绿，背景素材、Logo 与 Favicon 使用方块拓扑方向。
- 深色模式保留 B 高密度专业运维方向，表面层级、文字对比与主色变量已纳入深色测试守护。
- 页面壳、侧栏、顶栏、平台首页、全部服务器、节点、监控总览、日志中心、服务器统一控制台、群组网络、任务中心、通知中心、客户端分发、用户与权限、系统设置等页面已按当前全站基调收口。

## 替代方案

- **继续以早期靛蓝圆角舒展风作为默认**：观感友好，但品牌记忆点弱，且不够运维密度。放弃作为默认。
- **把 B 暗色高密度作为默认**：专业感强，但不符合用户确认的 A 亮色默认方向。保留为暗色模式方向。
- **为每页自定义视觉**：短期看灵活，长期不可维护。放弃。
